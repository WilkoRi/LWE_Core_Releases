# Projectafspraken

Dit prototype blijft bewust eenvoudig. De Local Website Editor is een lokale beheerlaag voor websitecontent.

Wel doen:

- tekst aanklikken
- tekst aanpassen
- opslaan naar JSON
- 11ty opnieuw bouwen
- normale website en Local Website Editor-editlaag gescheiden houden

Niet doen in deze fase:

- automatische refresh
- afbeeldingen vervangen of uploaden via de editor
- database
- externe CMS-koppeling
- gebruikersbeheer
- complexe block-builder
- drag-and-drop

De waarde van dit prototype zit in de eenvoud: een AI kan de website bouwen zolang hij de JSON- en template-afspraken volgt.

Voor grotere wijzigingen moet de AI eerst een voorstel doen en akkoord vragen voordat hij echt gaat bouwen.
